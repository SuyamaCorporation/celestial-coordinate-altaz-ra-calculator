# Celestial Coordinate Alt/Az ↔ RA/Dec Converter

Bidirectional converter between Horizontal (Altitude/Azimuth) and Equatorial (Right Ascension/Declination) coordinate systems using spherical trigonometry and sidereal time computation.

## Key Features

- Two conversion modes: Alt/Az → RA/Dec and RA/Dec → Alt/Az
- Observer location inputs (latitude, longitude) and UTC datetime for accurate sidereal time
- Computes Greenwich Mean Sidereal Time, Local Sidereal Time, and Hour Angle
- Results displayed in both degrees/hours decimal and DMS/HMS formatted notation
- Collapsible formula reference panel explaining each spherical trig step
